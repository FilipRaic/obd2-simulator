Events the interface receives

  1. Move the joystick or turn the encoder.
Joystick up, down, left, right - navigation
Joystick, click - select and start editing
Encoder - changes the value, a faster turn gives a bigger step
Encoder button - wired, the software does not use it
CONFIRM stores, CLEAR reverts, RETURN goes back
Fault codes - click selects a code, left and right change its state
CLEAR with no code selected asks before erasing them all
